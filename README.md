# Pocket: FX-сканер сигналов (Telegram Mini App)

Нажимаешь кнопку, и приложение проверяет 8 валютных пар (без OTC) по 7 стратегиям. Если у какой-то пары есть сигнал, у которого на истории этой пары было преимущество над точкой безубыточности, оно показывает пару, направление (вверх или вниз) и время экспирации, а затем рисует график с живым обновлением. Если такого сигнала нет, приложение говорит «не заходить».

**Что приложение не делает:** оно не читает график и не управляет терминалом Pocket Option. У платформы нет публичного API, а автоматизация через обходные пути нарушает её правила. Сигнал это подсказка, решение и вход остаются за тобой.

## Как это работает

1. Загружает 1000 свечей по каждой паре (источник: Twelve Data, либо демо-данные).
2. Каждая из 7 стратегий ищет событие на последней закрытой свече (описание правил: [docs/STRATEGIES.md](docs/STRATEGIES.md)).
3. Для каждой стратегии на истории этой пары считается, как часто её сигналы сбывались через 1, 2 и 3 свечи. Результат сглаживается (как будто было 10 побед и 10 поражений заранее), чтобы случайная серия удач на малой выборке не выглядела закономерностью.
4. В сигнал идут только стратегии, у которых сглаженный результат выше точки безубыточности (при выплате 85% это около 54%). Их преимущества суммируются по направлению.
5. Выбирается пара с наибольшей суммой и экспирация, на которой она больше. Это рейтинг, а не вероятность: настоящую вероятность угадать нельзя.

## Запуск

```bash
python3 -m http.server 8000     # открой http://localhost:8000
node test/engine.test.js        # тесты движка
```

Тесты, среди прочего, проверяют, что стратегии не «заглядывают в будущее»: сигналы на обрезанной истории совпадают с сигналами на полной.

## Публикация как Telegram Mini App

1. На GitHub: **Settings → Pages → Deploy from a branch → main / root**. Адрес будет вида `https://<логин>.github.io/Pocket/`.
2. В Telegram открой @BotFather, создай бота (`/newbot`), затем привяжи Mini App: `/newapp` или `/setmenubutton` и вставь адрес из шага 1.
3. Открой бота, перейди в **Настройки** внутри приложения, выбери «Twelve Data» и вставь свой ключ с [twelvedata.com](https://twelvedata.com).

## Ограничения

- Бесплатный тариф Twelve Data: 8 запросов в минуту. Подбор по 8 парам использует весь лимит, поэтому живой график обновляется раз в 20 секунд и может ждать окна.
- Ключ хранится только в `localStorage` на устройстве. Запросы идут из браузера напрямую, если провайдер заблокирует это (CORS), понадобится маленький сервер-прокси.
- Forex закрыт на выходных: приложение это определяет по устаревшим свечам и пишет об этом.
- Цены брокера могут немного отличаться от рыночных. Перед входом сверяй цену в терминале.
- Это не финансовая рекомендация. Результат на истории не гарантирует результат в будущем. Сначала проверяй на демо-счёте.
